# Массив на странице. Список фильмов

## Как создать элемент в JavaScript

`document.createElement('li')` создаёт новый элемент `<li>` и возвращает его. В скобках пишем имя тега без угловых скобок. Новый элемент пока существует только в JavaScript. Его можно настроить, а затем вставить на страницу.

```js
const item = document.createElement('li');
item.textContent = 'Поезд на север';
movieList.append(item);
```

`movieList` здесь — уже найденный на странице элемент `<ul>`. Вызов `movieList.append(item)` помещает новый пункт в конец этого списка. Так же можно создать кнопку через `document.createElement('button')` и добавить её внутрь пункта через `item.append(removeButton)`.

## Чем отличаются `textContent` и `innerHTML`

Оба свойства заменяют содержимое элемента. `textContent` вставляет строку как текст. `innerHTML` разбирает строку как HTML и создаёт элементы из тегов.

```js
result.textContent = '<strong>Поезд на север</strong>';
// На странице видна вся строка, включая <strong> и </strong>.

result.innerHTML = '<strong>Поезд на север</strong>';
// На странице видно название, выделенное жирным.
```

В списке фильмов используем `textContent` для названий из поля ввода, чтобы браузер отображал их как текст. Запись `movieList.innerHTML = ''` очищает список и убирает из него все пункты.

## Как вывести массив в HTML

У каждого фильма есть название и обложка. Названия храним в массиве `movieTitles`, а пути к картинкам — в массиве `moviePosters`. Элементы с одинаковым индексом относятся к одному фильму. Например, `movieTitles[0]` — название первого фильма, а `moviePosters[0]` — его обложка.

В HTML создаём пустой список `<ul>`. Через `forEach()` проходим по названиям. Для каждого названия берём обложку по тому же индексу и добавляем один `<li>`.

Сохраните пример в `example.html`. Рядом создайте папку `covers` и положите в неё три JPG-картинки с именами `space.jpg`, `house.jpg` и `train.jpg`. Откройте страницу в браузере.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Список фильмов</title>
</head>
<body>
  <h1>Что посмотреть</h1>
  <ul id="movieList"></ul>

  <script>
    const movieTitles = [
      'Космическая станция',
      'Тайна старого дома',
      'Поезд на север',
    ];
    const moviePosters = [
      'covers/space.jpg',
      'covers/house.jpg',
      'covers/train.jpg',
    ];
    const movieList = document.getElementById('movieList');

    function renderMovies() {
      movieList.innerHTML = '';

      movieTitles.forEach((movieTitle, index) => {
        const item = document.createElement('li');

        const poster = document.createElement('img');
        poster.src = moviePosters[index];
        poster.alt = '';
        poster.width = 64;

        const title = document.createElement('span');
        title.textContent = movieTitle;

        item.append(poster, title);
        movieList.append(item);
      });
    }

    renderMovies();
  </script>
</body>
</html>
```

Свойство `src` указывает браузеру, какую картинку загрузить. Здесь `alt` можно оставить пустым, потому что название фильма уже написано рядом с обложкой. `renderMovies()` очищает список перед тем, как заново вывести названия и обложки из массивов.

## Как обновить список после изменений

Сначала меняем оба массива, затем вызываем `renderMovies()`. Чтобы добавить фильм, записываем его название и обложку в конец соответствующих массивов.

```js
movieTitles.push('Остров сокровищ');
moviePosters.push('covers/island.jpg');
renderMovies();
```

Чтобы удалить фильм, используйте `splice()` с одинаковым индексом в обоих массивах. Индекс `1` соответствует второму фильму. В примере `forEach((movieTitle, index) => { ... })` передаёт название первым параметром, а его индекс вторым.

## Задание. Список фильмов «Что посмотреть»

Создайте `index.html` на основе примера. Над списком разместите два поля и кнопку «Добавить». В каждой строке списка покажите обложку, название фильма и кнопку «Удалить».

### 1. Добавьте новый фильм

Поместите эти элементы перед `<ul>`:

```html
<label for="movieName">Название фильма</label>
<input id="movieName" type="text">
<label for="moviePoster">Ссылка на обложку</label>
<input id="moviePoster" type="text" placeholder="https://…">
<button id="addMovie" type="button">Добавить</button>
```

В обработчике `click` прочитайте `.value` обоих полей. Метод `.trim()` убирает пробелы по краям строки. Если после этого хотя бы одно поле пустое, завершите обработчик через `return`. Иначе через `push()` добавьте название в `movieTitles`, а ссылку на картинку — в `moviePosters`. Очистите оба поля и вызовите `renderMovies()`.

Во второе поле можно вставить прямую ссылку на изображение или путь к файлу из папки проекта, например `covers/island.jpg`.

### 2. Удалите фильм по кнопке рядом с ним

Внутри `forEach()` получите индекс вторым параметром и создайте для каждого фильма свою кнопку через `document.createElement('button')`. Задайте ей текст «Удалить» и добавьте её в тот же `<li>` через `item.append(removeButton)`.

В обработчике клика этой кнопки удалите название через `movieTitles.splice(index, 1)`, а обложку через `moviePosters.splice(index, 1)`. Затем вызовите `renderMovies()`. Обработчик добавляйте внутри `forEach()`, чтобы каждая кнопка использовала индекс своего фильма.

- Поместите заголовок, поля и список в белый блок на светлом фоне. Добавьте блоку внутренние отступы и скруглённые углы.

### 4. Проверьте в браузере

1. При открытии страницы видны три фильма с обложками из массивов.
2. Добавьте «Остров сокровищ» и укажите ссылку на обложку. В конце списка появляются название и картинка, оба поля очищаются.
3. Нажмите «Добавить», оставив одно из полей пустым. Список остаётся прежним.
4. Удалите второй фильм и проверьте, что у оставшихся фильмов по-прежнему правильные обложки. Затем удалите только что добавленный фильм.
5. Удалите оставшиеся фильмы и добавьте один новый. Он должен появиться в пустом списке.
6. Убедитесь, что новая строка оформлена так же, как исходные фильмы, а её кнопка «Удалить» находится справа.
